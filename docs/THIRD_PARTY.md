# Third-party components

## mpvpaper

This repository includes ARM64 binaries for convenience:

- `bin/mpvpaper`
- `bin/mpvpaper-holder`

They were built on Debian 13 aarch64 from:

```text
https://github.com/GhostNaN/mpvpaper.git
commit 4de75e73b40ba9e953eaec9eaa7773e6c31ab08a
```

`mpvpaper` is GPLv3. Rebuild locally with:

```sh
./scripts/build-mpvpaper.sh
```
